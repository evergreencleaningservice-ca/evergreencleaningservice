# Competitor-to-Evergreen adaptation matrix

**Reviewed 15 October 2026.** The competitor pages were fetched directly that day, and every page cited returned HTTP 200. Raw HTML was kept in the session scratchpad and is not in this repository.

We adapted JAN-PRO's principles, not its wording, imagery, brand names or visual design. JAN-PRO's own claims (its stats, awards and named systems such as "JAN-PRO Tracker") were **not** verified and are not used as benchmarks.

## What was deliberately not adapted

- **Franchise structure.** JAN-PRO has local offices and a local number per city. Evergreen has one office, and its pages now say so.
- **Named proprietary systems** and **numeric claims** (retention %, "#1", client counts). Nobody has supplied an Evergreen equivalent, so none was written.
- **JavaScript counters and sliders for proof.** Evergreen's proof text is written straight into the HTML.
- **Interaction-gated analytics.** This is what most explains JAN-PRO US's 96 lab score. Evergreen's container includes Google's call-tracking number swap, which has to run before a visitor taps the number, so holding GTM until interaction would cost real phone-call attribution. It is a decision for the advertising owner, not a free performance win.
